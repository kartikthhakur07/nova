# Nova

A modular repository scaffold for a frontend, backend, data, and AI-enabled system.

## Structure

- `frontend/` - Application UI and client-side code.
- `backend/` - API, agents, and services.
- `qdrant/` - Vector DB collections, seed data, and ingestion tooling.
- `rime/` - Streaming, speech, and latency-related components.
- `data_simulator/` - Synthetic data sources, scenarios, and schemas.
- `evaluation/` - Tests and evaluation result storage.
- `demo/` - Demo assets and example flows.
- `assets/` - Architecture artifacts, screenshots, and branding resources.
